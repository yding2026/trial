## 怎么替换照片？

### 方法一：直接改 index.html（推荐）

1. 把你的照片放到 `images/` 文件夹里，比如 `images/comp-01.jpg`
2. 用记事本或 VS Code 打开 `index.html`
3. 搜索 `<!-- <img src="images/competition-01.jpg"` 这样的注释
4. 把注释去掉，改成你的照片路径：

```html
<!-- 改之前 -->
<!-- <img src="images/competition-01.jpg" alt="竞赛照片1"> -->

<!-- 改之后 -->
<img src="images/comp-01.jpg" alt="数学建模比赛">
```

5. 同时修改照片下方的标题和描述文字

## 怎么修改内容？

- **替换头像**：搜索 `about-avatar-placeholder`，把里面的"俞"字换成 `<img>` 标签
- **改联系方式**：搜索 `替换为你的微信号` 等字样，改成你的真实信息
- **改技能**：搜索 `技能与方向` 下方的卡片内容
- **添加更多照片位**：复制一张照片卡片的 HTML 代码，粘贴后修改即可
